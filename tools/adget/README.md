# adget — 参考広告のダウンロードとライブラリ化

「この広告いいな」と思った投稿の URL を渡すと、動画をローカルに保存し、
あとから見返せる資料として整理して溜めていくコマンドです。

X / Instagram / TikTok / YouTube / Facebook / Vimeo ほか、yt-dlp が対応するサイト全般で動きます。

---

## 導入（初回のみ）

Mac のターミナルで、このリポジトリのあるディレクトリに移動して：

```bash
git pull
./tools/adget/install.sh
```

`install.sh` がやること：

1. Homebrew の有無を確認（無ければ導入コマンドを案内して停止）
2. `yt-dlp` と `ffmpeg` を導入 / 最新化
3. `~/.local/bin/adget` にシンボリックリンクを張り、PATH を通す
4. 保存先 `~/Movies/AdSwipe/` を作成

何度実行しても壊れません。X は仕様変更が多く古い yt-dlp が動かなくなるため、
**動かなくなったら install.sh をもう一度実行**すれば最新版に更新されます。

---

## 使い方

```bash
adget "https://x.com/sankei_bldg/status/2095072762264240554"
```

URL を省略すると**クリップボードの中身**を使います。
投稿の URL をコピーしてから、ターミナルで：

```bash
adget
```

まとめて処理することもできます：

```bash
adget "https://..." "https://..." "https://..."
cat urls.txt | adget
```

### オプション

| オプション | 内容 |
|---|---|
| `-c, --cookies <browser>` | ログインが要る投稿用。`chrome` / `safari` / `firefox` / `brave` / `edge` |
| `-d, --dir <path>` | 保存先を変更（既定 `~/Movies/AdSwipe`） |
| `-f, --force` | 保存済みでも取り直す |
| `-r, --reveal` | 完了後に Finder で表示 |
| `--no-sheet` | サムネシートを作らない |
| `-h, --help` | ヘルプ |

## ホットキーにする（本命の使い方）

コピー → キー一発、でターミナルを開かずに保存できます。macOS 標準の
ショートカット.app だけで完結します。

1. **ショートカット.app** を開き、左上の「＋」で新規ショートカットを作成
2. 右の検索欄で「シェルスクリプトを実行」を探し、ドラッグして置く
3. 設定を次のようにする
   - シェル: `zsh`
   - 入力: `入力なし`
   - スクリプト欄に1行貼る：
     ```
     $HOME/.local/bin/adget
     ```
4. 名前を `広告を保存` などにする
5. 右パネルの ⓘ →「キーボードショートカット」で好きなキーを割り当てる（例: `⌥⌘D`）

以降は **投稿の URL をコピー → 割り当てたキー** で保存されます。
完了・失敗は macOS の通知で出ます（ターミナルから実行したときは通知ではなく画面に出ます）。

> ショートカット.app から呼ばれると PATH が最小構成になりますが、`adget` は
> Homebrew のパスを自分で通すので、フルパスで書けばそのまま動きます。

## 何が保存されるか

```
~/Movies/AdSwipe/
├── index.tsv                                    ← 全件の索引
└── 2026/
    ├── 2026-09-03_x_sankei_bldg_2095072762264240554.mp4
    ├── 2026-09-03_x_sankei_bldg_2095072762264240554.info.json
    └── 2026-09-03_x_sankei_bldg_2095072762264240554.sheet.jpg
```

ファイル名は `投稿日_媒体_アカウント_投稿ID` に統一されます。
Finder で名前順に並べれば時系列、媒体別・アカウント別の絞り込みも効きます。

| ファイル | 中身 |
|---|---|
| `.mp4` | 動画本体（最高画質の映像＋音声を mp4 に統合） |
| `.info.json` | キャプション全文、投稿日、尺、解像度、再生数など全メタデータ |
| `.sheet.jpg` | 全尺から等間隔に抜いた9フレームを 3×3 に並べたシート。**構成とカット割りを一目で見るため** |

サムネシートは尺の 5.6% 地点から 94.4% 地点までを9等分した時刻から抜いています。
広告は最後に商品名や CTA が来るため、末尾が欠けないことを優先しました。

`index.tsv` は1行1本の索引です。列は
`保存日時 / 媒体 / アカウント / 投稿日 / 尺(秒) / 解像度 / URL / キャプション / ファイル名`。
タブ区切りなので、そのまま Google スプレッドシートや Numbers に貼れます。
本数が増えたときに「縦型15秒だけ」「このアカウントだけ」で絞るのはここでやります。

## うまくいかないとき

**「ログインが必要」「not available」と出る**

非公開・年齢制限・地域制限のかかった投稿です。ブラウザでログイン済みの状態にして、
Cookie を借りて再実行します（`adget` 自身がこの案内を出します）。

```bash
adget -c chrome "https://..."
```

毎回付けたくない場合は `~/.zshrc` に：

```bash
export ADGET_BROWSER=chrome
```

Safari の Cookie を使う場合は、ターミナルに「フルディスクアクセス」の許可が要ります。
Chrome のほうが素直に通ります。

**急に全部落ちなくなった**

X 側の仕様変更で yt-dlp が追いつけていない可能性が高いです。

```bash
./tools/adget/install.sh
```

で最新に更新してください。それでも駄目なら数日待つと yt-dlp 側が対応します。

**サムネシートだけ作られない**

`ffmpeg` / `ffprobe` が見つからないか、動画の尺が取れていません。
動画本体の保存は成功しているので、`--no-sheet` を付ければ警告は消えます。

## 環境変数

`~/.zshrc` に書いておくと既定値が変わります。

| 変数 | 用途 |
|---|---|
| `ADGET_DIR` | 保存先ルート。例 `export ADGET_DIR="$HOME/Dropbox/AdSwipe"` |
| `ADGET_BROWSER` | Cookie を借りるブラウザの既定値。例 `export ADGET_BROWSER=chrome` |
| `ADGET_YTDLP` | 使う yt-dlp のパス。X の仕様変更直後に nightly 版へ逃がすとき用 |
